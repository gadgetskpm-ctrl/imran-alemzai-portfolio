## Security and repository policy

Do not commit:

- passwords or account credentials
- API keys or private tokens
- private environment files
- database service-role credentials
- webhook secrets
- customer or client-confidential information
- production admin credentials
- internal automation secrets
- private LeadBridge implementation details

Sensitive configuration must be stored in the deployment platform or another approved secret-management system rather than in source control.

See [SECURITY.md](SECURITY.md) for responsible reporting guidance.
