    05

    How I work

    Plan every move before execution.
    Build with clear checkpoints and evidence.

    1. 01 / DISCOVER

      Understand

      Define the business goal, audience, constraints, and measure of success.

      Output · Project brief
    2. 02 / PLAN

      Map

      Set scope, priorities, milestones, responsibilities, risks, and approval points.

      Output · Delivery roadmap
    3. 03 / DESIGN

      Prototype

      Shape the system, content, interface, and workflow before full production begins.

      Output · Approved direction
    4. 04 / EXECUTE

      Build

      Develop the agreed solution in focused stages with visible progress reviews.

      Output · Working build
    5. 05 / VERIFY

      Validate

      Test usability, accessibility, performance, content, and edge cases against the plan.

      Output · QA sign-off
    6. 06 / DELIVER

      Launch

      Release carefully, document the system, and define the next improvement cycle.

      Output · Launch package
